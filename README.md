## 📚 Exercícios de Java — Lógica de Programação

Repositório com 50 exercícios práticos de Java, cobrindo desde entrada de dados básica até estruturas condicionais (`if`, `else if`, operador ternário) e `switch case`.

### 📌 Sobre

Os exercícios simulam cenários simples do dia a dia (cadastro de aluno, compras, salário, temperatura, login, caixa eletrônico, cardápio, posto de combustível, entre outros), usando `Scanner` para capturar dados do usuário e praticando conceitos de forma progressiva.
